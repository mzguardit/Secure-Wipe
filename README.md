## Overview

**Secure Wipe** is a Windows data sanitization tool created in **2010** by **Vincenzo Chieppa (SoftEdition / MZGuard)**. Standard deletion only removes file pointers, leaving data recoverable with forensic carving tools. Secure Wipe overwrites sensitive files, folders, and unallocated free disk space using multi-pass cryptographic and government sanitization standards.

## Supported Sanitization Standards

* **Pseudorandom Data:** Fast single-pass or multi-pass random byte overwriting.
* **RCMP TSSIT OPS-II:** Canadian government technical security standard.
* **US DoD 5220.22-M (3-pass):** Department of Defense data sanitization standard.
* **ECE (7-pass):** Extended multi-pass overwrite pattern.
* **Gutmann (35-pass):** Maximum-depth 35-pass magnetic media sanitization algorithm.

---

## Core Capabilities

* **File & Folder Shredding:** Permanently overwrite individual files or entire directory trees.
* **Free Disk Space Wiping:** Sanitize unallocated clusters to erase remnants of previously deleted files.
* **Windows Explorer Integration:** Quick context-menu shredding directly from the file manager.
